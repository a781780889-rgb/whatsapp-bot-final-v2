# لوحة تحكم واتساب الاحترافية (WhatsApp Control Panel)

نظام متكامل لإدارة حسابات واتساب المتعددة (Messenger & Business) عبر واجهة رسومية سهلة الاستخدام.

## المميزات
- إضافة عدد غير محدود من الحسابات.
- دعم مسح QR Code للربط.
- مراقبة حالة الحسابات لحظياً (متصل، منفصل، بانتظار QR).
- نظام نسخ احتياطي للجلسات (Session Backup).
- سجل عمليات كامل (Audit Logs).
- إحصائيات النظام المتقدمة (استهلاك الذاكرة، المعالج، وقت التشغيل).
- واجهة مستخدم SaaS احترافية (Enterprise Dashboard Header).
- محرك بحث عالمي ذكي (Live Search Center) مع اختصارات لوحة المفاتيح.
- نظام تنبيهات وإشعارات متكامل.
- دعم الوضع الليلي (Dark Mode) وتصميم عصري متجاوب بالكامل.
- شريط جانبي (Sidebar) قابل للطي لتوفير مساحة العمل.

## متطلبات التشغيل
- Node.js (v18+)
- pnpm أو npm

## طريقة التشغيل
1. قم بفك الضغط عن الملف.
2. افتح المجلد في Terminal.
3. قم بتثبيت المكتبات:
   ```bash
   pnpm install
   ```
4. قم بتشغيل الخادم:
   ```bash
   pnpm start
   ```
5. افتح المتصفح على: `http://localhost:3000`

## هيكل المشروع
- `server/`: يحتوي على الكود البرمجي للخادم والتعامل مع واتساب.
- `public/`: يحتوي على واجهة المستخدم (HTML/JS/CSS).
- `sessions/`: يتم تخزين جلسات واتساب هنا بشكل آمن.
- `database/`: قاعدة بيانات SQLite لتخزين بيانات الحسابات.
- `backups/`: نسخ احتياطية للجلسات.

## ملاحظات أمنية
- يتم تشفير بيانات الجلسات داخل مجلد `sessions`.
- لا تقم بمشاركة مجلد `sessions` مع أي شخص غير موثوق.
